Andrew's Password Manager

Functionality:

Password Generator
  a. Use the slider to select password length
  b. press set length button -> unlocks generate pass button
  c. press generate pass button -> generates strong password

Password Strength Checker
   a.Input your password into the text box
   b. press check password
   c. system will generate a password rating and recommendations to make password stronger
   
Secure Password Storage
  1. Store Passwords
    a. Enter service name, username, plaintext password, master password
    b. press store password -> password encrypted using master password and stored in database

  2. Get Passwords
     a. Enter Master password
     b. press get password -> passwords decrypted and displayed
     c. search bar
     d. sort by service name or username
